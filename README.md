# Fintech Data Warehouse

## О проекте

Учебный проект по построению ETL-пайплайна для загрузки и обработки транзакционных данных и формирования аналитической витрины в Vertica.

В проекте реализован полный поток обработки данных:

**S3 → Apache Airflow → Vertica Staging → DWH → аналитическая витрина**

Основная задача проекта — автоматизировать загрузку транзакций и курсов валют, рассчитать показатели транзакционной активности и оборота и обеспечить ежедневное обновление витрины.

## Что реализовано

* организована загрузка CSV-файлов из S3 в Vertica;
* реализована batch-загрузка транзакционных данных;
* создан Staging-слой для транзакций и курсов валют;
* настроены сортировка, распределение и партиционирование таблиц в Vertica;
* разработана аналитическая витрина `global_metrics`;
* реализован расчёт общего оборота, количества транзакций, среднего количества транзакций на аккаунт и количества активных аккаунтов;
* настроено ежедневное обновление витрины через Apache Airflow;
* реализовано инкрементальное обновление данных с помощью `MERGE`;
* добавлены SQL-проверки загрузки и результатов обработки.

## Аналитическая витрина

Витрина `global_metrics` формируется в разрезе даты и исходной валюты.

Основные показатели:

* `amount_total` — общий оборот;
* `cnt_transactions` — количество транзакций;
* `avg_transactions_per_account` — среднее количество транзакций на аккаунт;
* `cnt_accounts_make_transactions` — количество аккаунтов, совершавших транзакции.

При расчёте учитываются транзакции со статусом `done`. Суммы транзакций конвертируются с использованием справочника курсов валют.

## Инкрементальное обновление

Для обновления `global_metrics` используется `MERGE`.

Витрина обновляется за конкретную дату:

* существующие записи обновляются;
* новые комбинации даты и валюты добавляются.

Это позволяет обновлять только необходимые данные без полной перезагрузки витрины.

## Контроль данных

Для проверки результата предусмотрены SQL-запросы, которые позволяют контролировать:

* количество транзакций по дням;
* количество успешно завершённых транзакций;
* количество записей в справочнике валют по датам;
* наличие данных в аналитической витрине.

## Результат

В результате создан автоматизированный ETL-процесс от получения исходных данных из S3 до формирования аналитической витрины в Vertica.

Проект демонстрирует работу с:

* пакетной загрузкой данных;
* Staging-слоем и DWH;
* Apache Airflow;
* S3-совместимым объектным хранилищем;
* SQL-трансформациями и агрегациями;
* инкрементальным обновлением аналитической витрины;
* базовыми проверками качества и полноты данных.
